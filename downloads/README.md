# 本地版下载

优先下载 Research-Studio.html，用 Chrome 打开，不需要部署网站或安装 Python。

GitHub 下载方法：打开文件，点击 Download raw file（下载原始文件）。也可在仓库首页点击 Code → Download ZIP，解压后进入 downloads 文件夹打开 HTML。

支持切换研究概览、词库、实验设置、翻译记录、每日计划、修改历史，含上传候选表的 426 个词条。

记录保存在当前电脑的当前浏览器中；不要使用无痕窗口。每天导出 JSON 备份到本机。移动文件、更换浏览器或清理浏览器数据后，可从备份恢复。此应用不调用翻译模型，不上传记录，不做云端同步。

Mac ZIP 额外提供浏览器启动器。不是经过签名的原生应用。如系统拦截，直接打开 HTML；无需关闭系统安全保护。
